# home-ai-server-Estoria
What it is...
Home AI server to create graphical images depicting the theme of the story submitted each day.
Everything written here is from my own perspective and genuine thought process.
There will be no AI generated entries in this README.md file. 

Brainstorming as a beginner with a solid foundation...
Build my own AI server able to create graphics from a journal-type-story entry I submit each day. The AI model will be texting me with reminders, prompts if I don’t know what to write about, and questions about my story to write and compose in a more compelling format. My AI server will then generate a simple graphic that depicts the theme or subject of that story and place it in a calendar like chart on an app. This way I can refresh my actual memory of any interesting stories that happened last week, last month, or last year.

The Purpose...
To learn practical homelab, ai, and security concepts, practice on a real-world project, and really build something that I can use as a source of experience to reflect back on when being interviewed for potential careers.
So far I have mainly used Claude and my co-workers as my main source of information and knowledge (I work as a helpdesk tech at a higher education institution). 

What I have learned right off the bat...
I knew a little bit about hosting servers, mainly from watching many home labbing videos and also from the cybersecurity boot camp I attended. The main question I had was, "What will be the easiest, cheapest, and most practical way to not only host a server, but host a server running AI models. I know it sounds cheap and a way to cut corners but Claude is right there to provide all the different avenues and possibilites. We (Claude and I) have settled on using an old, decommissionsed Microsoft Surface Book 2 that my institution was going to scrap. This machine has  500GB Storage, 16GB RAM, 6BG VRAM, Intel Core i7-8650U, NVIDIA Gforce GTX 1060. I fully understand this machine will only be able to run APIs to the AI models I choose to run, so I will not be running my any Models locally. Also, the GPU in this Surface Book 2 can only host older, lighter image gerneation models. So I'll have to play around with this and maybe figure out another model I can use an API for.
Honestly, I still have to fully grasp how to use APIs work and the nuances behind them if there are any. 
I will be installing an Ubuntu server on my Surface Book 2 to begin.
